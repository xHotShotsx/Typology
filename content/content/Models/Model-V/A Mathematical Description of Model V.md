# The Structure

Model V (created by Vladmir Vincent) is very much similar to Model A in the regard that for both models, $\mathbb{S} \cong D_{4} \times \mathbb{Z}_{2}$ acts on the set of 8 functions transitively, and both models would be classified under $8T_{9}$ using GAP's classification code of finite transitive groups and share the same automorphism class, but the key thing that separates them is that the elements used are different. In Model A, the standard information elements are used, whereas in Model V, elements that are shared by mirror pairs are used, which I will call 'mirror elements' (MEs for short). So, Model V can be described by $F$ (the set of functions) and the set 

$$ M = \{ \text{?(NT)}, \text{!(SF)}, \text{?(NF)}, \text{!(ST)}, \text{!(NT)}, \text{?(SF)}, \text{!(NF)}, \text{?(ST)} \}$$

of mirror elements. Formally, $\mathbb{S}$ acts via pre-compositions on the set of bijections from $F$ to $M$ in Model V and the set of types $T$ can be defined as all arrangements which result from applying every permutation in $\mathbb{S}$. 

## The Surjection

# Systems of Injections for Model V

An acceptable system of injections on Model V must arise from an index-2 subgroup of $\mathbb{S}$ corresponding to a _converse_ dichotomy. These include Irrational/Rational, Extroverted/Introverted, Process/Result, and Asking/Declaring.

The reason for this restriction is structural. Each mirror element $m \in M$ admits a decomposition into its associated monadic elements in $\mathcal{E}$, and any admissible injection must preserve this correspondence. Equivalently, for every function in $F$ either the unsplit element $m$ or exactly one of its associated monadic refinements must be present, uniformly across all types.

Index-2 subgroups not associated with converse dichotomies (these are the *vector* dichotomies, which when intersected define the 'Challenge Response' tetrachotomy) fail to satisfy this condition, as they induce splittings that cannot be reconciled with the monadic decomposition of elements in $M$. Consequently, no other index-2 subgroup of $\mathbb{S}$ satisfies the uniform monadic-refinement constraint above.

## Classification Proposal of the 'B-Models'

$\text{V}[\mathbb{S}]$: Model defined by the full transitive $D_{4} \times \mathbb{Z}_{2}$ action on the set of 8 functions. Baseline Model V with the Mirror Elements (MEs).    
$\text{V}[\mathbb{S}/C_{1}]$: Model that is theoretical. Irrational/Rational $\cong \mathbb{Z}_{2}^3$ serves as the basis here, which has a transitive action on the set of 8 functions.    
$\text{V}[\mathbb{S}/C_{2}]$: Theoretical model. The basis is Extroverted/Introverted $\cong D_{4}$ which acts transitively on the set of 8 functions.  
$\text{V}[\mathbb{S}/C_{3}]$: Model deployed by the School of Classical Socionics (SCS) and School of Humanitarian Socionics (SHS) for Model G. The basis is Process/Result $\cong \mathbb{Z}_{2} \times \mathbb{Z}_{4}$ which acts transitively on the set of 8 functions.  
$\text{V}[\mathbb{S}/C_{4}]$: Model that is theoretical. Positivist/Negativist $\cong D_{4}$ is the basis here, which acts transitively on the set of 8 functions.
